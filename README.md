# Skilled Nursing PDPM Reimbursement Integrity

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 90 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, audit history, and at least 15 PostgreSQL records per capability.

Run `./start.sh`, then open <http://127.0.0.1:4595>. API: `5595`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
